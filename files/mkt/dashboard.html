No구분경로할 일
1늘리기구글·네이버 검색자료 받기와 문의 작성의 대부분이 검색에서 나옵니다. PLC 프로그램 개발·노후 제어반 교체·예지보전 주제로 홈페이지 사례·질문 답변 글을 매달 1~2개 더합니다.
2늘리기네이버 플레이스·구글 비즈니스지도에서 찾는 고객용입니다. 사진과 소식을 주 1회 올리고, 홈페이지 링크는 /np · /gb 짧은 주소를 씁니다.
3고치기네이버 블로그방문은 오는데 참여율이 낮고 문의 작성이 없습니다. 글 끝에 관련 페이지 링크를 하나씩 넣습니다(제어반 글 → 제조기업 도입, PLC 글 → PLC 프로그램 개발).
4늘리기스레드·인스타그램스레드는 방문과 자료 받기가 꾸준하고, 인스타는 적은 방문에도 문의 작성이 나왔습니다. 주 2~3회 짧은 현장 소식을 이어 갑니다.
5유지AI 검색(ChatGPT 등)AI 답변을 보고 들어오는 방문이 생겼습니다. 홈페이지의 회사·제품 설명을 정확하게 유지하는 것이 곧 AI 노출입니다.
6고치기제조기업 도입 페이지방문자는 많은데 머무는 시간이 짧습니다. 첫 화면에 「설비 고장을 데이터로 미리 알림」 사례 하나와 문의 버튼을 크게 둡니다.

숫자를 볼 때 알아 둘 점

  • 숫자는 구글 애널리틱스 기록을 매일 아침 구글 시트로 모은 것입니다. 열 때마다, 그리고 열어 둔 동안 10분마다 새로 읽습니다.
  • 지금 이 순간 접속자는 휴대폰 Google Analytics 앱의 「실시간」에서 봅니다.
  • 직접 방문에는 직원 방문도 섞여 있습니다. 구글 애널리틱스에서 회사 인터넷 주소를 빼면 더 정확해집니다.
  • 경로 묶음(예: 네이버 블로그 여러 개를 「네이버 블로그」로)은 대시보드를 만들며 정한 분류입니다. 광고·봇이 남기는 가짜 유입(스팸 사이트)은 숫자에서 뺐습니다.
