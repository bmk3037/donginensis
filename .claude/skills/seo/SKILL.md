# 홈페이지 SEO 점검·보강

## 1. 점검
```
python3 _src/seo/check_seo.py      # 국문
python3 _src/seo/check_seo.py en   # 영문
```
- 페이지마다 제목·설명 길이, H1 1개, 대체 글(alt) 없는 그림, canonical·hreflang, 사이트맵 포함을 본다.
- 목표 검색어: ★(1순위)는 제목·설명·본문 모두, ·(2순위)는 설명이나 본문 중 한 곳에 있어야 한다. 「제어반을 제작」처럼 조사·짧은 말이 끼어도 같은 말로 센다.
- 결과를 표로 사용자에게 보여 주고, 「← 보강」 줄부터 고친다.

## 2. 목표 검색어 정하기·바꾸기
- `_src/seo/keywords.json`에 페이지별로 적는다(국문 main/sub, 영문 en_main/en_sub). 한 검색어는 한 페이지가 맡는다(여러 페이지가 같은 1순위를 다투지 않게).
- 우리가 만든 말(「지능형 제어반」)만 쓰지 말고, 사람들이 실제 검색하는 말(제어반 제작, 자동제어반, PLC 제어반, 예지보전, 선박 제어반 등)을 함께 둔다.
- 실제 유입 검색어·순위는 네이버 서치어드바이저·구글 서치콘솔 화면에서만 알 수 있다. 사용자에게 화면을 받아 검색어를 고른다(검색량을 지어내지 않는다).

## 3. 고치는 규칙
- 순위에 영향을 주는 곳은 제목(title)·설명(description)·H1·본문 글·그림 대체 글·내부 링크다. `meta keywords`는 구글은 보지 않고 네이버도 거의 반영하지 않으니 페이지 주제에 맞게만 둔다(다른 페이지 것을 복사하지 않는다).
- 제목: 국문 15~40자, 영문 70자 이내. 앞쪽에 핵심 검색어. 설명: 국문 50~120자, 영문 160자 이내.
- H1은 페이지당 1개. 디자인 문구(슬로건)는 그대로 두고, 검색어는 제목·설명·본문 문장에 자연스럽게 넣는다. 같은 말을 억지로 반복하지 않는다.
- 사실만 쓴다(공장 위치·실적·인증은 홈페이지·회사소개서에 있는 것만).
- og:title·og:description이 제목·설명과 같던 페이지는 같이 바꾼다(메인 og는 홍보 문구라 따로 둔다).
- 바꾼 페이지는 `sitemap.xml`의 lastmod를 오늘 날짜로.
- 국문·영문은 같은 작업에서 함께 고치고 `python3 _src/check_ko_en.py` 통과(CLAUDE.md).

## 4. 마무리
- 두 점검이 모두 「모든 목표 검색어가 들어 있습니다」, 점검 「이상 없음」이 되면 커밋·PR·머지 후 실서버에서 제목·설명이 바뀌었는지 확인한다.
- 사용자에게: 네이버 서치어드바이저·구글 서치콘솔에서 사이트맵 다시 제출, 바뀐 주요 페이지 「수집 요청」을 안내한다.
