FAQ

자주 묻는 질문

동인엔시스와 귀사의 역할은 어떻게 나뉘나요?

동인엔시스는 현장 쪽(OT)을 맡습니다. 제어반 설계·제작·설치, PLC·인버터·센서 연동, 클라우드·고객사 서버로의 데이터 전송과 표준 데이터 제공까지가 동인엔시스의 범위입니다. MES·AI 분석·디지털트윈·고객 대상 서비스는 귀사 솔루션을 그대로 활용하고, 동인엔시스는 신뢰할 수 있는 현장 데이터를 제공하는 데 집중합니다. 협업 모델 보기 →

어떤 PLC를 지원하나요?

특정 제조사에 한정되지 않습니다. 신규 설비는 MQTT를 지원하는 PLC로 지능형 제어반을 구성해 별도 게이트웨이 없이 직접 연결합니다. 미쓰비시·LS·지멘스 등 이미 설치된 타사 PLC는 데이터를 읽기만 하며, OPC UA, Modbus TCP, 제조사 전용 프로토콜(게이트웨이) 순서로 현장에 맞는 방식을 정합니다. 기종과 통신 방식은 현장 분석에서 확인해 프로젝트별로 제안해 드립니다.

기존 제어반이 있는 현장도 연동할 수 있나요?

가능합니다. 기존 제어반의 상태와 PLC 기종을 현장 분석에서 확인해, 지능형 제어반으로 교체·신규 설치하거나 기존 설비와 연동하는 방식 중 적합한 방법을 제안합니다. 설비(모터·펌프 등)는 그대로 사용합니다.

어떤 데이터를 받을 수 있나요?

모터 권선온도(U·V·W), 베어링 온도, 회전속도, 전압·전류·전력량, 진동, 대기 온습도, 운전 상태신호 등을 수집합니다. 센서마다 값·단위와 함께 기준값에 따른 상태(normal·warning·alarm)가 붙어, 귀사 시스템에서 별도 가공 없이 쓸 수 있습니다. 샘플 데이터 받기 →

데이터는 어떤 방식으로 받을 수 있나요?

REST API로 설비·센서 목록, 최신값, 기간별 이력을 조회하고, WebSocket으로 측정값과 상태 변경을 실시간으로 받습니다. 테스트·분석용으로 CSV 내보내기도 제공합니다. 엔드포인트, 인증 방식, 갱신 주기 등 세부 규격은 기술 미팅에서 협의합니다. 연동 개요서 받기 →

통신이 끊기면 데이터는 어떻게 되나요?

통신이 끊겨도 설비 제어는 현장 PLC가 계속합니다. 끊긴 동안의 측정값은 제어반에 보관했다가, 연결이 복구되면 오래된 순서대로 자동으로 다시 보냅니다. 측정 시각은 현장에서 기록하고 메시지마다 순번을 붙여, 서버에서 중복과 누락을 가려냅니다.

데이터 형식은 표준으로 정해져 있나요?

네. MQTT 토픽 구조, 메시지 형식, 표준 Tag 이름 규칙을 정한 동인엔시스 OT 데이터 규격을 기준으로 구성하며, 규격에는 버전을 붙여 관리합니다. 설비 제조사나 현장이 달라도 같은 구조로 데이터가 들어옵니다. 세부 규격 문서는 NDA 체결 후 기술 미팅에서 제공합니다.

데이터 통신이 설비 제어에 영향을 주지 않나요?

설계 단계에서 제어와 통신을 나눕니다. 제어 로직은 우선순위가 높은 작업으로, 데이터 전송은 그보다 낮은 작업으로 분리하고, 제어망과 데이터망도 나눠 구성합니다. 통신량과 제어 주기 기준은 프로젝트별로 협의해 시운전 단계에서 확인합니다.

설비가 늘어나면 연동을 다시 개발해야 하나요?

아닙니다. 모든 설비가 '현장 → 설비 → 센서 → 값·상태'의 같은 구조로 제공되므로, 설비나 센서가 추가돼도 기존 연동 코드를 그대로 쓸 수 있습니다.

고객사가 온프레미스 구축을 원하면 어떻게 하나요?

DataHub와 대시보드를 고객사 서버·사내망에 설치하는 온프레미스형으로 구성할 수 있습니다. 서버는 고객사 보유 서버를 활용하거나 동인엔시스가 공급합니다. 클라우드형과 같은 데이터 구조와 API로 제공되어, 귀사 시스템을 사내망 안에서 그대로 연동할 수 있습니다.

보안 검토에는 어떻게 대응하나요?

현장과 클라우드·고객사 서버 사이 MQTT 통신은 TLS로 암호화되고, 인터록과 최종 제어 권한은 현장 PLC가 보유해 서버가 설비를 직접 제어하지 않습니다. 접속 계정·권한과 데이터 보관 기간은 프로젝트 계약에서 정하며, 네트워크 구성은 고객사 보안 정책에 맞춰 협의합니다. 보안 구성 보기 →

현장에 설치된 제어반의 펌웨어와 보안 인증서는 어떻게 관리하나요?

설치된 제어반마다 PLC 모델, 펌웨어·프로그램 버전, 인증서 만료일을 대장으로 관리하는 것을 원칙으로 합니다. 펌웨어·프로그램 변경은 사전 시험과 고객 승인을 거쳐 진행하고, 원격 접속은 고객이 승인한 보안 연결(VPN)로만 합니다. 세부 운영 방식은 고객사 보안 정책에 맞춰 계약 시 정합니다.

선박용 제어반의 선급 승인은 어떻게 받나요?

지능형 제어반에 쓰는 슈나이더 Modicon M262 컨트롤러는 한국선급(KR)·DNV·ABS·LR 등이 상호 인정하는 선급 인증서(EU RO 상호인정, 하드웨어 기준)를 보유하고 있습니다. 제어반과 응용 프로그램은 선박별로 해당 선급의 도면 승인과 검사관 입회 시험(FAT)을 거쳐 승인받습니다.

본 계약 전에 테스트해 볼 수 있나요?

네. 먼저 샘플 데이터로 귀사 시스템에서 구조를 확인하고, 이후 시연 장비와 테스트 데이터로 귀사 플랫폼과의 실제 연동을 검증할 수 있습니다. 검증 범위와 일정은 기술 미팅에서 정합니다.

현장 시공과 전기 안전 책임은 누가 지나요?

제어반 설계·제작·설치와 시운전, 유지보수는 동인엔시스가 맡습니다. 35년간 제어반을 직접 설계·제작해 온 OT 엔지니어링 기업으로서, 제어반 개조·설치에 따르는 현장 작업을 책임지고 수행합니다. 표준 구축 기간은 9~15주이며 현장 조건에 따라 달라질 수 있습니다.

공동 영업이나 정부 지원사업 참여도 가능한가요?

가능합니다. 제조 고객을 함께 발굴하고, 스마트공장 공급기업으로서 정부 지원사업에 공동으로 참여할 수 있습니다. 시연 장비를 활용한 공동 제안·영업도 진행합니다. 공동 제안·영업 모델 보기 →

데이터 소유권과 계약 구조는 어떻게 되나요?

프로젝트별 계약에서 고객사·귀사·동인엔시스 간 역할과 책임, 데이터 소유·이용 범위, 보관 기간을 정합니다. 필요하면 기술 미팅 단계부터 NDA를 체결합니다.
