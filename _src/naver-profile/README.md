# 네이버 스마트플레이스(업체 프로필) 등록 자료

네이버 지도·검색에 나오는 업체 정보를 **네이버 스마트플레이스**(smartplace.naver.com)에 등록할 때 그대로 복사해 쓰는 문구와 사진입니다.
문구는 홈페이지(`index.html`, `company.html`)의 내용만 썼습니다. 사진은 `python3 build.py`를 실행하면 `photos/` 폴더에 다시 만들어집니다.

> 본사·연구소·양산 1·2공장·기장공장을 각각 하나의 업체로 등록할 수 있습니다. 우선 **본사** 1곳만 등록하고, 공장은 필요할 때 추가하는 것을 권장합니다 (아래 "사업장별 등록" 참고).

## 등록 순서

1. smartplace.naver.com 접속 → 네이버 로그인 → **업체 신규 등록**
2. 업체명·주소로 검색해 이미 등록된 업체가 있으면 **소유권 확인(사업자등록증)**, 없으면 신규 등록
3. 위 1~5번 내용을 입력하고 사진 업로드 (첫 번째 사진이 대표사진)
4. 네이버 검토 후 노출 (보통 며칠 소요)
