# 네이버 스마트플레이스(업체 프로필) 등록 자료

네이버 지도·검색에 나오는 업체 정보를 **네이버 스마트플레이스**(smartplace.naver.com)에 등록할 때 그대로 복사해 쓰는 문구와 사진입니다.
문구는 홈페이지(`index.html`, `company.html`)의 내용만 썼습니다. 사진은 `python3 build.py`를 실행하면 `photos/` 폴더에 다시 만들어집니다.

> 본사·연구소·양산 1·2공장·기장공장을 각각 하나의 업체로 등록할 수 있습니다. 우선 **본사** 1곳만 등록하고, 공장은 필요할 때 추가하는 것을 권장합니다 (아래 "사업장별 등록" 참고).

```

[제조업 DX/AX, 왜 현장 데이터인가]
대부분의 공장 설비는 이미 PLC와 인버터로 제어되고 있지만, 그 안에서 만들어지는 데이터는 제어반 밖으로 나오지 못하고 사라집니다.
AI와 스마트팩토리가 제 역할을 하려면 설비의 운전 데이터가 먼저 필요합니다.

[지능형 제어반으로 시작하는 DX/AX]
- 설비를 제어하는 제어반이 운전 데이터를 함께 수집합니다.
- 별도 수집장비(게이트웨이, 산업용 PC) 없이 클라우드나 사내 서버로 바로 연결합니다(MQTT/TLS).
- 모터, 펌프의 온도, 전류, 진동을 24시간 기록하고, 이상 징후를 알람으로 먼저 알립니다.
- 표준 데이터 구조와 REST API로 MES, 관제, AI, 디지털트윈에 바로 연결합니다.
- 현장에는 지능형 제어반 1면만 설치하면 됩니다.

[이런 제조기업에 필요합니다]

- 스마트팩토리, MES, AI 도입을 준비하는데 현장 데이터가 없는 공장

[IT기업과의 협업]
스마트팩토리, AI, MES 솔루션 기업에는 OT 파트너로서 제어반 설계, 제작, 설치, PLC 연동까지 현장 구간을 책임지고 표준 데이터를 제공합니다.

[구축 과정, 9~15주]
현장 분석(1주) - 지능형 제어반 제작(5주) - 서버 구성(2주) - 시운전 및 AI 학습(2~4주)

- ISO 9001, 14001, 45001, 벤처기업, 이노비즈, 메인비즈
```

## 등록 순서

1. smartplace.naver.com 접속 → 네이버 로그인 → **업체 신규 등록**
2. 업체명·주소로 검색해 이미 등록된 업체가 있으면 **소유권 확인(사업자등록증)**, 없으면 신규 등록
3. 위 1~5번 내용을 입력하고 사진 업로드 (첫 번째 사진이 대표사진)
4. 네이버 검토 후 노출 (보통 며칠 소요)
