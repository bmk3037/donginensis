통합경영 기록 시스템 DI-IMS-F-01 Rev.00

품질 ISO 9001 · 환경 ISO 14001 · 안전보건 ISO 45001

ISO 기록 묶음 생성기

프로젝트 정보와 BOM·I/O 리스트를 넣으면 통합 기록양식을 채워 프로젝트 폴더(01~08)째로 만들어 줍니다. 실측값·판정·서명 칸은 현장에서 직접 적도록 비워 둡니다.

예시 데이터 가상의 인버터 제어반 2면 프로젝트가 채워져 있습니다. 실제 고객·주문 정보가 아닙니다.

1프로젝트 정보

일정 (예정일 한 번 입력)

공정 이동표 일자, 시험일·작업일·시운전일, 설계 단계 일정에 '예정'으로 들어가고 기록 현황판이 다음 일정과 지연을 알려 줍니다. 날짜가 바뀌면 여기만 고쳐 묶음을 다시 만들고, 실제 한 날은 문서에 덮어씁니다.

결재란 (모든 문서 공통)

한 번 적으면 모든 문서의 작성·검토·승인 칸에 이름이 들어갑니다. 서명과 일자는 실제로 확인한 사람이 그때 직접 적습니다(미리 서명하지 않음). 05 회사 연간 기록 탭에 회사 담당자·명단을 적어 두면 '비우고 내 프로젝트 입력' 때 검토·승인자, 품질·생산 담당, 계측기, 외주 업체, 보관 경로가 미리 들어갑니다.

고객 요구 · 담당자
공용폴더·NAS 보관 정보

회사에서 승인한 경로·담당자를 입력하면 현황표에 반영됩니다. 실제 저장·접근권한·백업은 회사 저장소에서 설정하고 확인합니다.

저장 파일에는 고객·BOM·I/O·기준표 정보가 포함됩니다. 회사의 접근권한이 관리되는 저장소에 보관하세요. 엑셀에서 작성한 검사 결과·서명은 이 파일에 포함되지 않습니다. 도면 변경 대상은 판넬 Tag 목록 또는 ‘전체’로 입력합니다.

2판넬

판넬마다 배선 검사(QF-05), FAT 성적서(QF-06), I/O 점검표(QF-06-1), 공정 이동표(QF-16), 통전 확인(SF-02)이 따로 만들어집니다. LOT 번호는 판넬에만 매기며 제조번호가 곧 판넬 LOT입니다(명판 표시, QF-04 판넬 LOT·출하 이력).

도면 Tag설명제조번호 = LOT (명판)삭제

3부품표 (BOM)

AutoCAD·ERP에서 뽑은 BOM 엑셀(.xlsx, .xls, .csv)을 넣습니다. 주요 부품은 입고검사(QF-03)에 들어갑니다. 부품에는 LOT 번호를 따로 매기지 않습니다. 수량 기준을 선택하세요. 프로젝트 총수량은 판넬별로 배분하고 판넬 열을 채운 뒤 원본 총수량 BOM과 대조합니다.

프로젝트 원본 총수량 BOM

배분 전 원본을 별도로 넣습니다. 품명·모델·메이커·단위를 동일하게 쓰고 수량에는 숫자만 입력하세요(예: 수량 1, 단위 식). 원본의 모든 부품과 판넬별 배분 합계를 대조하며 누락·초과·원본에 없는 부품은 생성 전에 안내합니다. 원본 파일의 승인 Rev를 확인해 회사 저장소에도 보관하세요.

4I/O 리스트

도면이나 Machine Expert에서 뽑은 I/O 리스트를 넣으면 판넬별 I/O 점검표(QF-06-1)가 점별로 채워집니다. 구분 열이 없으면 주소(%IX, %QX, %IW, %QW)로 DI·DO·AI·AO를 정합니다.

5시험·검사 기준 (QF-15)

모델·정격·회로·고객 요구·규격·시험조건이 동일한지 확인한 기준만 재사용합니다. 변경 시 기술팀 검토·승인을 다시 받습니다. 기준값은 QF-15와 FAT 성적서(QF-06) 기준란에 들어갑니다.

만들어질 문서

    00_기록현황에는 프로젝트 기록과 공통기록참조 두 시트가 들어갑니다. 공급자·교정·자격·안전·환경·경영 기록은 회사 원본 경로를 연결하세요.

    • 자동으로 채움 프로젝트 번호·판넬 LOT(제조번호), 도면·PLC Rev, 부품 목록, I/O 점, 기준값, 기록 경로
    • 직접 적음 실측값, 합격·불합격, 서명·일자
    • 결과를 미리 채우거나 나중에 몰아서 서명하지 않습니다(매뉴얼 부록 E).
