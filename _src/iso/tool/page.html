품질 ISO 9001 · 환경 ISO 14001 · 안전보건 ISO 45001

ISO 기록 묶음 생성기

프로젝트 정보와 BOM·I/O 리스트를 넣으면 통합 기록양식을 채워 프로젝트 폴더(01~08)째로 만들어 줍니다. 실측값·판정·서명 칸은 현장에서 직접 적도록 비워 둡니다.

예시 데이터 가상의 인버터 제어반 2면 프로젝트가 채워져 있습니다. 실제 고객·주문 정보가 아닙니다.

2판넬

판넬마다 배선 검사(QF-05), FAT 성적서(QF-06), I/O 점검표(QF-06-1), 공정 이동표(QF-16), LOT 추적표(QF-04), 통전 확인(SF-02)이 따로 만들어집니다.

도면 Tag설명제조번호 (명판)삭제

3부품표 (BOM)

AutoCAD·ERP에서 뽑은 BOM 엑셀(.xlsx, .xls, .csv)을 넣습니다. 주요 부품은 입고검사(QF-03)와 LOT 추적표(QF-04)에 들어갑니다. 판넬 열이 없으면 모든 판넬에 같은 BOM을 씁니다.

4I/O 리스트

도면이나 Machine Expert에서 뽑은 I/O 리스트를 넣으면 판넬별 I/O 점검표(QF-06-1)가 점별로 채워집니다. 구분 열이 없으면 주소(%IX, %QX, %IW, %QW)로 DI·DO·AI·AO를 정합니다.

5시험·검사 기준 (QF-15)

같은 타입 판넬은 기술팀 총괄이 한 번 승인한 기준표를 계속 씁니다. 기준값은 QF-15와 FAT 성적서(QF-06) 기준란에 들어갑니다.
